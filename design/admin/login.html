Masuk sebagai admin

Peran admin tidak pernah diberikan lewat API — hanya lewat seed atau operasi database.

Scope membatasi menu. Penegakan sebenarnya tetap di backend (ADMIN_SCOPE_DENIED).
Akun demo: admin@example.com (penuh), kurator@example.com (catalog), support@example.com (notifications + reports). Email tanpa kata admin/kurator/support akan ditolak.
